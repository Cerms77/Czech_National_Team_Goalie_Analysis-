# Czech National Team Goaltender Evaluation

### NHL & AHL Goaltending Analytics | 2026–27 Season

I created this Python-based analytics project to evaluate Czech goaltenders competing in the NHL and AHL. The goal is to compare individual performances against league-wide and Czech goaltending averages to help identify strengths, weaknesses, and potential national team candidates.

This project is a sample demonstration that I plan to update ahead of the 2027 IIHF World Championship.

### Interactive Dashboard

**[View the Goaltender Evaluation Dashboard](https://cerms77.github.io/Czech_National_Team_Goalie_Analysis-/)**

I developed three interactive models:

1. **Goaltender Search:** View individual player statistics, league rankings, and comparisons against league and Czech averages.
2. **Interactive Leaderboard:** Rank Czech goaltenders by different statistics, including save percentage, goals against average, and advanced metrics.
3. **Performance Comparison:** Visualize each goaltender's performance relative to their respective league average.

### Statistics and Methodology

The project uses traditional goaltending statistics such as save percentage, goals against average, total saves, and workload.

For NHL goaltenders, I also evaluate advanced statistics including:

- Goals Saved Above Expected (GSAx)
- High-danger scoring opportunities
- Low-danger goals allowed relative to expectations
- Rebound control
- Expected goals against per 60 minutes

Using Python, I calculate individual statistics, rankings, and averages to better understand goaltender performance beyond traditional statistics alone.

NHL and AHL goaltenders are evaluated separately, with advanced statistics included where data is available.

### Data and Technology

- **Data:** MoneyPuck NHL goaltending data and AHL goaltending statistics
- **Season:** 2026–27, through November 5, 2026
- **Programming:** Python
- **Data Analysis:** Pandas and NumPy
- **Website:** HTML, CSS, and JavaScript
- **Hosting:** GitHub Pages

### Project Purpose

My goal is to combine my hockey experience with data analytics to develop tools that can support player evaluation and Hockey Operations decisions.

This model is intended to provide additional statistical context and support professional scouting, not replace video analysis or traditional player evaluation.
